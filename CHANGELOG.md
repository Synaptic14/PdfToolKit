The format is inspired by Keep a Changelog and the project follows SemVer for its public API surface.

## [1.0.0]

Initial public release planned with:

- Native PDF generation for the main text, graphics, image, metadata, annotation, outline, and form workflows
- Native PDF import for declared PDF versions `1.0` through `1.8`
- Imported-page overlay and common imported editing workflows
- Practical Unicode-capable font embedding, shaping, and subsetting
- Practical layout helpers for flowing text, panels, tables, grouped record tables, and multi-column composition
- Practical Standard Security import/export coverage
- Documented public API boundary, compatibility guide, and runnable examples
